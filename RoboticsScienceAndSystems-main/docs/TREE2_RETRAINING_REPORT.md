# 实测转弯数据的 Tree2 训练报告

2026-11-19，模型版本 `measured-forward-v1`。默认固件的前进分支调用一棵 12 叶 CART。独立测试集包含 160 轮、11,610 条转弯记录，固件取整前的差速请求相对记录指令的 MAE 从 15.237 降到 2.845 PWM，RMSE 从 19.776 降到 4.625 PWM。在剩余角 0°～5° 区间，为了在目标附近收回差速，部署版的指令拟合误差升高。新控制器的实车超调、稳定时间和路线成功率仍待测量。[固件集成与实车验证状态](../TREE2_HARDWARE_INTEGRATION_REPORT.md)

## 数据来源与审计

`controldata/` 内有 111 个 CSV。36 个采集会话各含原始时序、轮次汇总和角度分箱各一份。左转 5° 的三个 `(1)` 文件分别与对应原件的 SHA-256 相同，各计一次。实验覆盖左右各 5°～90°、每 5° 一档，每档每方向 20 轮，共 720 轮，汇总状态均为 `completed`。11 月 17 日采集左转，18 日采集右转 5°，19 日采集其余右转。方向和日期相关，跨日条件的影响无法单独辨识。每个会话的名称、拆分、记录数及原始文件摘要均保存在[机器可读训练记录](tree2_training.json)。

| 原始时序字段 | 记录的量与单位 |
|---|---|
| `timestamp_ms`, `trial_elapsed_ms` | 会话时间戳、轮内经过时间，ms。时间戳在每个原始文件内递增 |
| `trial`, `direction`, `phase` | 轮次编号、L/R、实验阶段。初始等待有 trial 0。一次实验用文件名和 trial 联合标识 |
| `target_angle_deg`, `turn_angle_deg` | 目标角幅度、朝本次转向累计的转角，°。右转的累计进度也通常为正 |
| `straight_travel_mm`, `straight_end_mm` | 直行进度及直行结束时的距离，mm |
| `target_left_mm_s`, `target_right_mm_s` | 左右轮目标速度，mm/s |
| `left_mm_s`, `right_mm_s`, `center_mm_s` | 记录的左右轮及车体中心速度，mm/s |
| `left_pwm`, `right_pwm`, `pwm_right_minus_left` | 两轮指令及右减左，整数 PWM 单位。逐行核对差值相等，所有原始阶段的单轮指令为 0～73 |
| `left_count`, `right_count` | 两轮累计编码器计数 |
| `x_mm`, `y_mm`, `theta_rad` | 里程计平面位置，mm，及逆时针为正的航向，rad |

- 原始时序去重后有 323,825 行。WAIT 141,543，STRAIGHT 103,060，TURN 43,198，SETTLE 35,988，DONE 36。原始与汇总表均无空值，数值列无无穷值。TURN 轮内相邻采样间隔中位数和 P95 均为 20 ms，最大 222 ms。
- 汇总表共 720 行。字段为 `trial, direction, target_deg, status, straight_end_mm, final_angle_deg, angle_error_deg, turn_sample_count, mean_left_pwm, mean_right_pwm, mean_pwm_difference, mean_center_mm_s`。核对了每轮 TURN 样本数、两轮 PWM、差值及中心速度的均值。`angle_error_deg = final_angle_deg − target_deg`。全部终角都与 SETTLE 后首条 WAIT/DONE 对齐，11 轮的最后一条 SETTLE 尚未到该终角。
- 分箱表共 34,200 行。字段为 `trial, angle_bin_start_deg, sample_count, mean_left_pwm, mean_right_pwm, mean_pwm_difference`。575 个空箱各有三个空均值。用非负累计转角向下取整重建 1° 箱，复算的计数和均值吻合。箱内合计 43,168 条，另有 30 条略负的转角进度保留在原始训练或评估数据中。两种派生表均不作为额外训练样本。
- 左转 80° 第 5 轮记录到最大差值 +51，对应左 22、右 73。该轮按原划分留在验证集。训练使用原始 TURN 标签，没有按误差大小剔除轮次。[审计实现](../tools/tree2_data.py)

## 75° 翻号、小角度和叶跳变

**75° 翻号的可复现条件。** 在一条直线上以 ±75° 初始航向误差调用实际 `Controller.cpp`，Tree1 选 FORWARD。旧 Tree2 的角度分裂中没有 75° 这个阈值。旧教师保留上一差值的 65%，镜像只能保证整对输入一起镜像时输出反号。顺时针 +75°、前次差值为 0 时，旧版输出 −37.610。前次差值为 +70 时，旧版输出 **+9.266**，最终左 7、右 16。该历史值可来自反方向的饱和 ROTATE 命令。当前次要求顺时针时，这个结果方向错误。新前进树在两种历史下均输出 **−14.784**，按最终速度规则写出左 9、右 −6。

穷举每个合法整数历史轮差 −200～+200，旧版 +75° 前进在 +56～+200 翻号，−75° 在 −200～−56 翻号，各 145/401。旧版倒车对应阈值为 ±55，各 146/401。新版四组均为 0/401。历史模型的全角度等轮速检查将前次差值固定为零，因此看不到该现象。实测测试集也未观察到旧版翻号。以上锁定了当前归档代码的一种失效机制，追溯原来那一次实车事件仍需当时的模式、角误差及左右命令记录。

**接近零误差。** 原实验在剩余角 ≤5° 时仍保持转弯轮速设定，全数据左转平均 +18.264、右转 −14.483 PWM，到角后再进入零 PWM 的 SETTLE。单纯模仿会在零点两侧切换两个非零叶，产生 33.095 PWM 的阶跃。部署时在训练叶中心之间插值，并以 (0, 0) 分隔左右两支。±0.36° 内差速为零，宽度约为日志中两次 0.179° 的编码器角度增量。带外使用 `90 × max(|eCW| − deadband, 0)` 限制差速幅度。90 PWM/rad 来自旧教师的名义转向增益。死区和增益是控制设计值，后续需用实车验证静摩擦和迟滞。

**其余叶边界。** 扫描覆盖近全圈、原始分裂的相邻 float、每个新叶中心和死区边缘。前进等历史轮速时，旧模型在 −18.286° 附近相邻浮点输入之间跳变 5.908 PWM。新部署曲线在检查网格上最大相邻变化为 0.1571 PWM，对应 0.1° 步长。端点外保持边缘叶值。采用空间插值可避免增加一个控制周期的滤波延迟。跨模式或突然更换目标仍可产生时间上的指令变化，STOP 继续当周期归零。[部署规则](../StampC3_Template/Tree2ControlPolicy.h)

## 路线仿真与前进基准调整

初次仅替换差速并进行平滑，原来的平均 PWM 在部分弯道上过大。八条课程动力学路线只有五条通过。直角、S 形在 300 s 超时，残距为 5.115、21.070 mm，最后 200 个采样均为 ROTATE，交替写出 (+35, −35) 和 (−35, +35)。这些末段命令来自独立旋转分支。更早的前进轨迹决定了进入该状态的位姿。

差速驱动的曲率取决于两轮速度差与平均速度之比。在现有理想轮速与 PWM 成比例的模型下，前进平均指令乘以 `min(1, |实测树请求| / 名义差速请求幅度)`，可以在实测差速较小时保留名义转弯曲率。名义幅度用上述带死区的增益，最高 140 PWM，与旧教师上限一致。死区内保持直行基准。该规则只降低平均 PWM，保留树的差速请求，未调整 Tree1、独立旋转增益或终点判据。实际电机两侧增益和启转阈值需另测。
